## 6. Модули (Modules)

Каждый модуль в `src/modules/<module-name>/`:

- обязан иметь `index.ts` (точка входа);
- экспортирует UI-компонент;
- при использовании Redux дополнительно экспортирует:

```ts
export const reducer = {
  name: 'ModuleName',
  value: ModuleSlice.reducer,
};
```

`name` - это ключ в корневом `state`.

### Контейнеры (`containers/`)

Контейнер соединяет Redux (селекторы, `dispatch`) с UI. **Минимум разметки в контейнере:** без объёмной вёрстки и длинного JSX; карточки, секции, кнопки и формы — в `components/`, контейнер только композиция и пропсы/колбэки.
