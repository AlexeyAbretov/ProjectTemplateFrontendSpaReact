## 8. Как добавить новую страницу и роуты

1. создать `src/pages/my-page/`;
2. добавить `index.tsx` с экспортом `routes`;
3. добавить `my-page.tsx`;
4. при необходимости добавить пункт в шапку: в объект маршрута добавить `header: { label: '...', order?: number }` (сортировка по `order`, затем по URL; подробнее — раздел PageRegistry и страницы в `DOCUMENTATION.md`).

Роуты объединяются автоматически при `PageRegistry.load()`.
