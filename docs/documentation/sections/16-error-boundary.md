## 16. Error Boundary (обработка ошибок рендера)

`ErrorBoundary` перехватывает ошибки рендера дочерних компонентов и показывает fallback UI вместо падения всей страницы.

### Что перехватывает

- ошибки в рендере дочерних компонентов;
- ошибки в lifecycle-методах;
- ошибки в конструкторах дочерних компонентов.

### Что не перехватывает

- ошибки в event handlers (`onClick`, `onChange` и т.д.);
- асинхронные ошибки (`setTimeout`, `fetch`, promise);
- ошибки внутри самого boundary-компонента.

### Пропсы

- `children` - обязательный контент;
- `fallback` - кастомный UI при ошибке;
- `level: 'app' | 'page' | 'module'` - уровень границы;
- `componentName` - идентификатор для логирования.
